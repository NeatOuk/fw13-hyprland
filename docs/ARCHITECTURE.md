# Architecture

Component map of fw13-hyprland with the per-feature details. The rules (packages, sources,
user decisions, conventions, verification) are in [CLAUDE.md](../CLAUDE.md); this file is the
"how does X work" reference. Keep it accurate in the same commit as the change.

Paths: `lib/fw13/…` = `dotfiles/dot_local/lib/fw13/…` (→ `~/.local/lib/fw13`), `fw-…` scripts =
`dotfiles/dot_local/bin/executable_fw-…` (→ `~/.local/bin`), "store `x`" = key `x` in
`~/.config/fw13/settings.json` (lib/fw13/store.py).

## Installer

- **install.sh**: preflight → repos → packages → system files → login/power → fingerprint/services → user phase → report.
  - Skips the names in `~/.config/fw13/skip-packages` (Settings → Apps → Uninstall… of an optional app; logs "skipped (removed by you)").
  - Flags: `--yes --ci --system-only --user-only --minimal --with=a,b --without=a,b --print-plan`; env: `HYPR_COPR`, `REPO_URL`, `CHECKOUT`.
  - Optional groups (`OPT_GROUPS` + `GROUP_INFO` = "lists|description" at the top): games (40-gaming), ai (71-ai + ollama.service), android (72-android + scrcpy), remote (31-remote + devolutions-rdm.repo), warp (97-warp + its repo + warp-svc), firewall (94-rpm-build + 95-citadel + Citadel builds + citadel.service/enforce), messaging (94-rpm-build + Telegram build), ghostty (94-rpm-build + 98-ghostty + build), database (DBeaver RPM download), claude-desktop (94-rpm-build + 73-cowork + Claude Desktop repackage + vhost_vsock modules-load), obsidian (94-rpm-build + Obsidian repackage), localsend (Flathub app). Each step checks `on <group>`; everything else is core. Selection (`choose_groups`): base = all minus `~/.config/fw13/install-groups-off` (the groups left out, one per line, so groups added later are on; absent = all; ignored under `--ci` = all; an old `install-groups` file of selected groups is read instead when the new one is absent and replaced by `save_groups`), `--minimal` = none, then `--with`/`--without`; asked once interactively (no `--yes`/`--ci`/group flags, system phase), Enter keeps the base; `save_groups` writes it after "Continue?". `GHOSTTY=0` drops ghostty for that run only. Unselected groups are skipped, never removed; skip-packages still applies on top. `--print-plan` prints groups, repos, lists, packages and steps, then exits before any change.
  - Warns (banner + before Done) when neither gnome-shell nor plasma-workspace is installed: GNOME recommended, never installed.
- **packages/NN-\*.txt**: one package per line, `#` comments on their own line only (`pkgs()` splits on whitespace); `15-login`, `61-power` conditional; matugen is installed separately as `'matugen >= 4'` (needs the COPR).
- **repos/\*.repo**: vendor repos (vscode, mise, cloudflare-warp, devolutions-rdm).
- **rpm/**: specs we build locally: `telegram-desktop-official.spec` (`build_telegram_rpm` in install.sh).

### Package source details (sources and decisions: CLAUDE.md → Package sources)

- Vendor repo files: `repos/vscode.repo` (packages.microsoft.com), `repos/mise.repo` (mise.jdx.dev/rpm), `repos/devolutions-rdm.repo` (Devolutions' repo on Cloudsmith), `repos/cloudflare-warp.repo` (pkg.cloudflareclient.com).
- mise tools live in the user's `~/.config/mise/config.toml`. Pi = pi.dev, github.com/earendil-works/pi, MIT.
- **herdr**: from mise (`dot_config/mise/config.toml`, aqua backend: GitHub release, checksum verified); `dot_config/herdr/create_config.toml` turns off its own version check (mise updates it), anything else stays herdr's default.
- **LazyVim**: Fedora's neovim + ripgrep/fd-find/tree-sitter-cli/gcc (70-dev), lazygit from mise; config = LazyVim's starter as `create_` files in `dot_config/nvim/` (init.lua, lua/config/lazy.lua, lua/plugins/user.lua), so the user's edits are never overwritten. The user phase runs `nvim --headless "+Lazy! sync" +qa` after `mise install` (non-fatal). Icons come from kitty's bundled Symbols Nerd Font and Ghostty's built-in symbols (no Nerd Font package).
- gcr provides gcr-ssh-agent; strongswan is driven via swanctl; ollama runs as a system service.
- LocalSend `org.localsend.localsend_app` is not in Fedora.

### Built or downloaded by install.sh

- **Citadel** (`build_citadel_rpm`): `citadel` (github.com/NeatOuk/citadel-app, `main`, release stamped `.gitYYYYMMDD.<sha>`) + `citadel-helper` (github.com/NeatOuk/citadel-helper, tag `v1.3.2`), built with their own .spec files (no prebuilt packages exist); PySide6 + maxminddb in `packages/95-citadel.txt`, rpm-build/make/systemd-rpm-macros in `94-rpm-build.txt` (shared with Telegram and Ghostty). Override with `CITADEL_APP_REF`/`CITADEL_HELPER_REF`. User phase enables `citadel.service` and `citadel enforce on`. The helper's polkit rule lets wheel use it without a password (by design).
- **Claude Desktop** (`build_claude_desktop_rpm`): the .deb from Anthropic's apt pool at CLAUDE_DESKTOP_VERSION, checked against CLAUDE_DESKTOP_SHA256 (from the apt index), rpmbuild of rpm/claude-desktop-official.spec (`ar x` + `tar -xf data.tar.*`, files as shipped under /usr/lib/claude-desktop, bundled libs excluded from auto provides/requires, explicit Fedora Requires for the .deb's Depends, chrome-sandbox 0755 (userns sandbox), GNOME search provider + MIME XML installed as files instead of the maintainer scripts; apt repo/AppArmor parts dropped; zstd level 3 payload); skipped when the installed version-release matches; .deb and RPM deleted after install.
- **Obsidian** (`build_obsidian_rpm`): same shape for the official .deb from github.com/obsidianmd/obsidian-releases at OBSIDIAN_VERSION, checked against OBSIDIAN_SHA256 (GitHub's asset digest); rpm/obsidian-official.spec keeps /opt/Obsidian, links /usr/bin/obsidian, chrome-sandbox 0755, drops the AppArmor profile and the alternatives postinst. Obsidian updates its own app.asar in-app (~/.config/obsidian).
- **Telegram Desktop** (`build_telegram_rpm`): reads the version from telegram.org's download redirect, downloads the tarball (no checksum is published: HTTPS only) plus the launcher entry, D-Bus service and icons from github.com/telegramdesktop/tdesktop at the same tag, and builds `telegram-desktop-official` (`/opt/telegram`, `/usr/bin/Telegram`, `Conflicts: telegram-desktop`). Its self-updater is off via `/opt/telegram/externalupdater.d` (7.x reads it next to the binary, not in /etc; while the updater is on, Telegram writes its own `org.telegram.desktop._<hash>.desktop`, removed by the user phase). Re-running install.sh rebuilds when telegram.org has a newer version, otherwise it's a no-op.
- **Ghostty** (`build_ghostty_rpm`): downloads `release.files.ghostty.org/<v>/ghostty-<v>.tar.gz`, checks the pinned `GHOSTTY_SHA256` (verified once against the release's minisign signature), builds with the exact Zig from `build.zig.zon`'s `minimum_zig_version` (ziglang.org tarball checked against its index.json; Fedora 44's zig 0.16 is too new) and installs `ghostty-official` (`Conflicts: ghostty`; terminfo files the system already owns are dropped). Build deps in `packages/98-ghostty.txt`. `GHOSTTY=0` skips; bump = new `GHOSTTY_VERSION` + verified sha256.
- **framework_tool**: release binary from github.com/FrameworkComputer/framework-system into `/usr/local/bin`, checked against the pinned `FWTOOL_SHA256` (GitHub's asset digest); bump `FWTOOL_VERSION` + sha256 together; skipped when the installed file already matches.
- **scrcpy**: downloads `scrcpy-linux-x86_64-$SCRCPY_VERSION.tar.gz` (github.com/Genymobile/scrcpy), checks the pinned `SCRCPY_SHA256` (GitHub's asset digest), installs it to /opt/scrcpy (stamp /opt/scrcpy/.version) with a /usr/local/bin/scrcpy wrapper setting `ADB=/usr/bin/adb` (Fedora's android-tools, 72-android.txt; the bundled adb is not installed), a launcher entry in /usr/local/share/applications and the man page; phones are reachable without root through systemd's 70-uaccess (ADB/Fastboot); bump version + sha256 together.
- **Remote Desktop Manager launcher** (dotfiles, not install.sh): `~/.local/share/applications/com.devolutions.remotedesktopmanager.desktop` (chezmoiignore'd unless `remotedesktopmanager` is on PATH; TryExec) runs `fw-rdm`: LIBGL_DRI3_DISABLE=1 (with DRI3 its Avalonia/OpenGL window stays transparent on XWayland; still GPU-rendered without it) + AVALONIA_SCREEN_SCALE_FACTORS from `hyprctl -j monitors` (`eDP-1=1.875;DP-3=1.25`; XWayland gets no scaling under force_zero_scaling), then the vendor's `remotedesktopmanager` script (GDK_BACKEND=x11).
- **Wallpapers** (user phase, before chezmoi so `fw13.wallpaper.init()` adopts one): `fetch_wallpapers` reads `wallpapers/ml4w.txt` (sha256 + name), downloads each from raw.githubusercontent.com/mylinuxforwork/wallpaper at `ML4W_WALLPAPER_COMMIT` into `<xdg PICTURES>/Wallpapers` via a `.part` file, checks the sum, and records the name in `$STATE_DIR/wallpapers-ml4w` so a deleted picture isn't fetched again; a failed file only warns and is retried next run.
- **DBeaver CE**: downloads `dbeaver-ce-$DBEAVER_VERSION-linux-x86_64.rpm` (github.com/dbeaver/dbeaver releases) into `$STATE_DIR/dbeaver`, checks the pinned `DBEAVER_SHA256` (GitHub's asset digest), `dnf install`s it and deletes the file; skipped when `rpm -q dbeaver-ce` already has `DBEAVER_VERSION`. No repo, so `dnf upgrade` never updates it: bump version + sha256 together. Dotfiles (only when `dbeaver-ce` is on PATH, `.chezmoiignore`): `~/.local/share/applications/dbeaver-ce.desktop` shadows the packaged entry with `GDK_BACKEND=x11` (SWT on native Wayland leaves dialogs such as New Connection empty and hung) + `GTK_THEME=Adwaita:dark`, TryExec hides it after uninstall; a `create_` Eclipse theme pref seeds the e4_dark theme on first run.
- **LocalSend**: `flatpak install --user org.localsend.localsend_app`; port 53317 is not opened, so the laptop can send but not receive.
- **Claude Code**: `curl -fsSL https://claude.ai/install.sh | bash` → `~/.local/bin/claude`, self-updating (mise npm skipped the package's postinstall, so no binary).
- **Chromium policies**: links `/etc/chromium/policies/managed/fw13-theme.json` to `~/.config/fw13/theme/chromium-policy.json` (see Theming); installs the recommended policy `system/etc/chromium/policies/recommended/fw13-memory.json` = Memory Saver on, maximum savings, user can still change it.

## Root side (`system/`)

### system/usr/local/bin/

- **fw-vpn-ctl**: root side of the bar VPN toggle (see fw-vpn).
- **fw-vpn-config** `show <name>|write|delete <name>` (Python): root side of the strongSwan form in Settings → Network → VPN (pages/vpn_edit.py). pkexec action `org.fw13.vpn-config`, `auth_admin_keep`. `show` = non-secret fields + has_psk/has_password; `write` = JSON on stdin, validated, rendered from a FortiGate IKEv2 PSK+EAP template, 0600, old file → `<name>.conf.bak`, `swanctl --load-all`.
- **fw-timeshift-setup**: Timeshift config, mode auto-detected, every schedule_* off (CLAUDE.md rule 6): snapshots come from fw-updates apply (keeps only the newest "before dnf upgrade" one, `update_snapshots` asserted); setup.timeshift_state reports "before updates only" and fw-health treats it as OK with no age limit.
- **fw-grub-theme** `[DIR]`: user phase, sudo. Draws the theme as the calling user (`runuser … python3 -m fw13.grub` → `~/.config/fw13/theme/grub`: theme.txt, background.jpg = desktop.jpg cover-cropped to 2880x1920 + blur + 55 % toward bg, card_*/select_* 9-slice PNGs (Pillow rounded rects), logo.png = the gear SVG via GdkPixbuf), copies theme.txt + PNG/JPEG to `/boot/grub2/themes/fw13` (old images removed) + JetBrains Mono Regular/Bold 32 px `.pf2` (grub2-mkfont; 00_header loadfonts every .pf2 in the theme dir), sets GRUB_THEME/GRUB_TERMINAL_OUTPUT=gfxterm/GRUB_GFXMODE=auto/GRUB_TIMEOUT=3/GRUB_TIMEOUT_STYLE=menu in /etc/default/grub (first run keeps `.fw13-orig`), `grub2-editenv - unset menu_auto_hide`, grub2-mkconfig (fails loudly, grub.cfg untouched). No-op without GRUB or when GRUB_THEME names another theme. Theme changes reach GRUB only when it is re-run. `python3 -m fw13.grub test`.
- **fw-hibernate-setup** `[--dry-run] [undo | delay 1|3|never]`: y/N per step, idempotent.
  - Top-level subvol `swap` at /swap, RAM-sized `btrfs filesystem mkswapfile`, semanage swapfile_t + /swap var_t (logind must search it, else CanHibernate = AccessDenied), fstab pri=10 below zram, Timeshift exclude `/swap/***`, `dracut.conf.d/fw13-resume.conf`.
  - UEFI + systemd >= 255 → HibernateLocation EFI var, no `resume=` (grubby only without EFI). Refuses lockdown/non-btrfs/no space.
  - `delay` writes sleep.conf.d HibernateDelaySec + HibernateOnACPower=no + logind.conf.d HandleLidSwitch=suspend-then-hibernate/ExternalPower=suspend (battery only); fw-idle's battery suspend follows that file. Settings → Power "When the battery is very low" + "Then hibernate after". fw-system-menu shows Hibernate only when CanHibernate = yes.
- **fw-timeshift-restore**: rsync-mode restore on Fedora's root/home btrfs: snapshot root, rsync onto the copy, swap by rename; kernels side by side + grubby; holds Timeshift's lock; undo.
- **fw-health-root**: root health facts, plus `luks` {tpm2, pin} / null and `secure_boot` from the EFI var.
- **fw-disk-unlock** `password|tpm-pin|tpm`: Settings → Security via `sudo` in fw-term. `systemd-cryptenroll --wipe-slot=tpm2 [--tpm2-device=auto --tpm2-pcrs=7 --tpm2-with-pin=yes]`; refuses without a password/recovery slot, never removes it; `tpm` refused unless Secure Boot is on (PCR 7 is constant otherwise; the page hides it too). `tpm2-device=auto` in the volume's crypttab line (backup `crypttab.fw13.bak`) or `rd.luks.options` via grubby; `/etc/dracut.conf.d/fw13-tpm2.conf` adds tpm2-tss (removed for password); `dracut -f --regenerate-all`.
- **fw-charge-limit** (root, no args): copies `charge_control_end_threshold` into the Framework EC with `framework_tool --charge-limit` — the kernel threshold alone is not enforced on the FW13 AMD, it charged past 80 %. Run by fw-charge-limit.service at boot, the Mains udev rule, and Settings → Power's switch via pkexec: action `org.fw13.charge-limit` in `system/usr/share/polkit-1/actions/org.fw13.power.policy`, rule `50-fw13-power.rules` = wheel at the laptop, no password.
- **fw-wifi-country** (root, `CC` or `00`): Wi-Fi regulatory country — `iw reg set` now and `options cfg80211 ieee80211_regdom=CC` in `/etc/modprobe.d/fw13-wifi-country.conf` for the next boot (`00` removes it). Settings → Network → Wi-Fi country via pkexec: action `org.fw13.wifi-country` in `org.fw13.wifi.policy`, no rule (admin password, kept briefly). The list comes from wireless-regdb's `/usr/lib/firmware/regulatory.db`, names from iso-codes, the current country + 6 GHz from `iw reg get` (`fw13.net`).
- **fw-power-profile**: balanced on AC, power-saver on battery (user decision), via the PowerProfiles D-Bus API (PPD or tuned-ppd); a hand-picked profile lasts until the next plug/unplug. Run by fw-power-profile.service (boot) + `system/etc/udev/rules.d/90-fw-power-profile.rules` (Mains change).

### system/etc/

- **geoclue/conf.d/90-fw13-timezone.conf**: `[fw13-timezone]` allowed + `system=true`, so fw13.timezone gets a location without a GeoClue agent (none runs in Hyprland).
- **modprobe.d/fw13-charge-control.conf**: `cros_charge_control probe_with_fwk_charge_control=1` (the kernel skips Framework otherwise) → charge limit in UPower / power panel.
- **systemd/system/**: fw-health-root.{service,timer} (:30 hourly → `/var/lib/fw13/health-root.json`, 0644; install.sh copies the folder only if it has files), fw-power-profile.service, fw-charge-limit.service.
- **polkit-1/rules.d/50-fw13-vpn.rules** + `usr/share/polkit-1/actions/org.fw13.vpn.policy`: see fw-vpn.

## Dotfiles (`dotfiles/`, chezmoi source, `.chezmoiroot = dotfiles`)

- **.chezmoi.toml.tmpl**: one-time prompts (secrets) — never commit values.
- **dot_config/hypr/\*.lua**: `hyprland.lua` require()s monitors/displays/autostart/looknfeel(+theme)/input/windows/bindings/settings (fw-settings-generated)/local (Lua config; hyprlock/hypridle/hyprpaper keep their own .conf).
- **hypr/hyprlock.conf.tmpl**: tuigreet-style text box without a picture (user decision): console black/grey `$fw_tty_*` = theme.TTY, 80-column box on a 13x29 grid (16 pt; hyprlock sizes are physical pixels), hostname/user from chezmoi; lock.jpg is still rendered but unused.
- **dot_claude/modify_settings.json**: Claude Code statusLine for fw-claude-limits.
- **jarvis/**: `AGENTS.md` (Jarvis briefing incl. the What/Why/How rule for root actions), `CLAUDE.md` (imports `@MEMORY.md`).
- **dot_local/share/easyeffects**: Framework's FW13 preset + IR and our presets (see fw-speakers).

### Shared Python library (lib/fw13 → ~/.local/lib/fw13; scripts `sys.path.insert` ~/.local/lib)

- **hypr**: Lua hyprctl helpers.
- **bar**: `SIGNALS` = the waybar custom modules' `"signal"` numbers (config.jsonc), `refresh(name)` = `pkill -RTMIN+N -x waybar`; imported `as waybar` (several scripts have their own `bar()`). `python3 -m fw13.bar test` checks the table against config.jsonc.
- **panel**: single instance via `$XDG_RUNTIME_DIR/<name>.pid` checked against `/proc/<pid>/cmdline` (`running`/`close`/`claim`/`release`) for the layer-shell panels, fw-workspaces and fw-autobrightness; `right_margin(width)` centres a bar panel under the pointer. `python3 -m fw13.panel test` self-check.
- **displays**, **system**, **ui_display**. displays.save (Keep) also writes `~/.config/fw13/display-layouts.json` {sorted descriptions joined by \n: {desc: [x, y]}} (2+ monitors); `restore_layout()` (fw-workspaces daemon at start and on monitoradded/removed/configreloaded, before re-binding workspaces) applies the current set's saved positions with today's modes/scales, only when they differ (`placed`, pure); unknown sets, and sets where two monitors share a description (same model with no or a fake serial), are left to displays.lua. `python3 -m fw13.displays test`.
- **store**: `~/.config/fw13/settings.json`.
- **ui_theme**: flat CSS (incl. `.found` for search hits).
- **power**: power readouts + `tuning()` (read-only CPU driver/EPP/boost/platform profile/ABM/tuned readout); `warn_levels()` for fw-battery-warn.
- **als**: light sensor via SensorProxy + auto-brightness curve.
- **health**: fw-hwcheck hardware group + fw-health daily group; expected Framework values in one table, non-Framework → SKIP; `root_facts()`.
- **notify**: shared notification + session_env; crash-watch and health use it; `launch()`, `on_action()`.
- **sound**: wpctl; filter sources listed too; `apps()` = per-app volume (pw-dump Stream/Output/Audio, EasyEffects' own skipped). Noise suppression = our drop-in `~/.config/pipewire/pipewire.conf.d/fw13-noise.conf`: libpipewire-module-echo-cancel, aec/libspa-aec-webrtc, monitor.mode (no extra sink), source `fw13_noise_source` "Noise-cancelled microphone"; restart pipewire/pipewire-pulse/wireplumber, set it default, previous default in store `noise_prev_source` restored when off; Settings → Sound → Input.
- **net**: nmcli; passwd-file, never argv. **bt**: org.bluez via Gio.
- **hyprsettings**: settings.lua: verify-config in a temp copy, then write + `hl.config` live. Also `input.touchdevice.enabled` for My Framework → Touch screen (pages/framework.py, shown when `hyprctl -j devices` lists a touch device; on = override removed). Haptic feedback + Click force (`framework_tool --haptic-intensity` / `--click-force`, via pkexec) shows when a Touchpad HID descriptor has the Haptics usage page 0x0E. The EC can't be read unprivileged, so every EC combo preselects store `ec_settings` = {setting: [value, boot_id]}, written after a successful pkexec run (fan only within the same boot_id: the EC goes back to auto at restart); before any choice it shows "Choose…".
- **idle**: owns hypridle.conf; plugged-in and battery timeouts, store `idle_*[_battery]`, listeners call `fw-idle <action> ac|battery`.
- **terminal**: backend of fw-term.
- **vpn**, **warp**: backends of fw-vpn and fw-warp-panel.
- **apps** (Settings → Apps):
  - `launcher_entries()` = what fuzzel lists (desktop ids over XDG_DATA_HOME + XDG_DATA_DIRS, first wins, `[Desktop Entry] Type=Application`, not NoDisplay/Hidden; fw-launcher counts with it); source via one `rpm -qf` / `flatpak list --app` / Exec+path (Steam, Lutris, Wine…).
  - OPTIONAL = {app package or Flatpak id: (extra packages, note)}: steam(+steam-devices), lutris, telegram-desktop-official, chromium, code, RemoteDesktopManager, ghostty-official, dbeaver-ce, citadel(+citadel-helper), cloudflare-warp, easyeffects(+lsp-plugins-lv2, lv2-calf-plugins), LocalSend, ollama, android-tools (no launcher entry: `entryless()` adds a row named from NAMES when installed); build deps stay. dnf remove ollama stops + disables ollama.service itself (its %preun), models in /var/lib/ollama stay. They get Uninstall… = fw-term `bash -c` (`sudo dnf remove <pkg> <installed extras>` / flatpak uninstall, never -y) that appends every name to `~/.config/fw13/skip-packages` only after success and once rpm/flatpak no longer has it; install.sh skips those names (pkgs() filter, Telegram/Ghostty/Citadel builds, the DBeaver download, WARP repo + warp-svc, LocalSend, ollama.service enable, scrcpy download when android-tools is skipped); Apps → Removed apps = `apps.unskip()`.
  - "Remove pre-installed apps…" = `apps.remove_all_script()`: every installed OPTIONAL app in one interactive `sudo dnf remove` + a flatpak uninstall each, each recorded in skip-packages only once gone.
  - Everything else protected = packages/*.txt read from chezmoi's source (`~/.local/share/chezmoi/packages`, the whole repo) ∪ install.sh's checkout + BUILT rpms + LocalSend, packages one of those needs directly (`rpm -e --test`, read-only), fw-*/fw13-* entries, GNOME_NEEDS (gnome-software, nautilus, control-center, ptyxis, default viewers).
  - Updates from `system.package_upgrades()` (shared with `package_updates()`) + `flatpak remote-ls --updates` (bg, network).
  - pages/apps.py: Uninstall… = fw-term `sudo dnf remove <pkg>` / `flatpak uninstall --user|--system <id>` (never -y), Update all… = fw-updates apply (also `flatpak update --system` when system apps exist), list re-read when Settings regains focus. `python3 -m fw13.apps test` self-check. Startup apps (`fw13.autostart`): ~/.config/autostart over $XDG_CONFIG_DIRS/autostart by file name, kept when they'd run in Hyprland under systemd-xdg-autostart-generator's rules (OnlyShowIn/NotShowIn, Hidden, X-systemd-skip, X-GNOME-Autostart-enabled=false, TryExec/Exec found); Off = a user copy marked X-fw13-Disabled=true with Hyprland in NotShowIn (deleted by On), copies we didn't make get only their NotShowIn edited; REPLACED (chezmoi's blueman/nm-applet/WARP copies) and NEEDED (geoclue agent) have no switch. `python3 -m fw13.autostart test`. Reopen apps (`fw13.session`, store `session_restore`): fw-workspaces' daemon saves `hyprctl clients` (class → launcher id via StartupWMClass or id; kitty/Ghostty with the shell's cwd from /proc; special workspaces, fw-* windows and entry-less classes skipped) to ~/.local/state/fw13/session.json 10 s after the last open/close/move event (logout kills the daemon before that, so the last settled set survives); at login it runs `restore()` instead of `layout()`: `uwsm app -- <id>.desktop` once per app, `fw-term --dir` per terminal, new windows moved by address to their class's saved workspaces in order (monitor workspaces → laptop when the monitor is absent). `python3 -m fw13.session test`. Check now also runs `upstream.check()` (background): the installer-built apps' newest official release (GitHub releases/tags, Claude's apt index, telegram.org's redirect) vs the installed RPM and install.sh's pin (read from the chezmoi source); framework_tool/scrcpy count as at their pin.
